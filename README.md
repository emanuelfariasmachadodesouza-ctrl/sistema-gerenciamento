# Sistema de gerenciamento

Exemplo de portfólio: gerenciador de tarefas em HTML, CSS e JavaScript. Sem banco de dados: os dados ficam no `localStorage` do navegador.

## Deploy na Vercel
Suba para o GitHub e importe na Vercel (sem framework, sem build, sem variáveis).

## Rodar local
Abra `index.html` no navegador.
